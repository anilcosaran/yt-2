# Caption font licenses

The caption presets bundle five families from the Google Fonts repository at commit `73fc2ff52147e34a74804b500cf89ca219eac55d`. Montserrat Bold comes from the official `googlefonts/Montserrat` upstream at commit `93c725e051a647a975c2cf225e8330bdf2b198e1` because its static face is selected reliably by libass.

| Caption family | Bundled file | Upstream directory | License |
| --- | --- | --- | --- |
| Anton | `Anton-Regular.ttf` | `ofl/anton` | SIL Open Font License 1.1 |
| Bebas Neue | `BebasNeue-Regular.ttf` | `ofl/bebasneue` | SIL Open Font License 1.1 |
| Montserrat | `Montserrat-Bold.ttf` | `googlefonts/Montserrat@93c725e/fonts/ttf` | SIL Open Font License 1.1 |
| Oswald | `Oswald-Variable.ttf` | `ofl/oswald` | SIL Open Font License 1.1 |
| Archivo Black | `ArchivoBlack-Regular.ttf` | `ofl/archivoblack` | SIL Open Font License 1.1 |
| Playfair Display | `PlayfairDisplay-Italic-Variable.ttf` | `ofl/playfairdisplay` | SIL Open Font License 1.1 |
